| **Problem**                               | **Subproblem Definition**                                                                                                                                                        | **State Representation**                                                                                 |
|-------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| **1. Distinct Subsequences**              | Count the number of distinct ways to form **t[j:]** from **s[i:]**.                                                                                                              | **(i, j)** where *i* is the index in **s** and *j* is the index in **t**.                                |
| **2. Interleaving String**                | Determine if **s3** can be formed by interleaving **s1** and **s2**; that is, if **s3[i+j:]** can be built from **s1[i:]** and **s2[j:]** while preserving order.                | **(i, j)** where *i* indexes **s1** and *j* indexes **s2** (with **k = i+j** for **s3**).                |
| **3. Longest Common Subsequence**         | Find the length of the longest common subsequence (LCS) between **s1[i:]** and **s2[j:]**.                                                                                       | **(i, j)** where *i* is the index in **s1** and *j* is the index in **s2**.                              |
| **4. Longest Increasing Subsequence**     | Compute the length of the longest increasing subsequence (LIS) starting at a given index while maintaining an increasing order relative to the last chosen element.              | **(i, prev)** where *i* is the current index and **prev** is the last included value (or a marker).      |
| **5. Longest Palindrome Subsequence**     | Find the length of the longest palindromic subsequence in the substring **s[i...j]**.                                                                                            | **(i, j)** where *i* and *j* denote the starting and ending indices in **s**.                            |
| **6. Coin Change 1 (Minimum Coins)**      | Find the **minimum number of coins** required to make a given amount using an unlimited supply of coins.                                                                         | **(amount)** where *amount* is the remaining value to be formed.                                         |
| **7. Coin Change 2 (Combinations Count)** | Count the number of **distinct ways** (combinations) to form a given amount using an unlimited supply of coins, where the order of coins does not matter.                        | **(i, amount)** where *i* is the current index in **coins** and *amount* is the remaining value.         |
| **8. Partition Subset Sum**               | Determine if there exists a subset within an array **nums** that sums up to **target**, where **target** is typically half of the total sum (i.e., equal-sum partition problem). | **(i, target)** where *i* is the current index in **nums** and *target* is the remaining sum to achieve. |
